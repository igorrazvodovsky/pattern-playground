- *Editor plugins cannot add their own extensions* — `EditorProvider` receives an editor the host already created, so the extensions a plugin returns from `getExtensions` are never installed. The `Commenting` shortcut reaches the plugin through `editor.storage.editorContext`. Fixing it means the provider, or a hook beside it, creating the editor from the plugins' extensions.
