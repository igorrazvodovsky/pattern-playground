# Bubble menu

The surfacing of relevant actions at the point of selection, balancing immediate capability with uninterrupted flow. Currently realised within the [block-based editor](../?path=/docs/components-blockbased-editor--docs); the pattern extends to any context where content is selectable.

### Complementary
