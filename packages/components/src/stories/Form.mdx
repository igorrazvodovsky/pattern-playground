# Form

The mechanism that hosts a set of fields, governs how they are laid out, grouped, and submitted, and wires their validation. For the design moves a form coordinates — data entry, bounded choice, multi-step sequencing — see <PatternRef slug="form">pattern</PatternRef>.

<Story of={FormStories.Default} />

## Labels

- Every control has a visible, persistent label
- Mark the rarer case. If most fields are required, mark the optional ones; if most are optional, mark the required ones — don't decorate every field.

## Grouping with fieldset

When several controls answer one logical question — a radio group, an address block, a day/month/year date — bind them in a `<fieldset>` with a `<legend>`. 

<Story of={RadioButtonStories.Group} />

A composite field is the other case — one value split across several inputs that must be read together (a date, an address, a name). The legend names the whole; each [input](../?path=/docs/primitives-input--docs) keeps a short label:

## TODO: Validation and feedback

- Timing. Validate on submit by default; reserve inline (on-blur) validation for fields where early correction clearly helps. Never validate while the actor is still typing.
- Error summary. For longer forms, list errors at the top, each linking to its field, in addition to the inline message.
- Styling invalid controls. Use `aria-invalid` and a non-colour-only indicator; pair the field with its message via `aria-describedby`.

## Choosing an input

Control choice follows the shape of the data. When the valid values form a bounded set, use <PatternRef slug="bounded-choice">Bounded choice</PatternRef>'s set-size spectrum (radio → select → combobox → dual listbox). When the value is fully open — the user supplies it rather than picks it — reach for a free-text [Input](../?path=/docs/primitives-input--docs) or [Textarea](../?path=/docs/primitives-textarea--docs). When both are true — there's a set, but a value outside it is also acceptable — a combobox covers that middle ground, letting the user narrow existing options or type a new one.
The useful question is therefore "does the value come from a set, and is that set the only thing allowed?" rather than "free text or selection?".
