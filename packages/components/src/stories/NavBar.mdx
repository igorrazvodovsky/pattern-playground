# Nav bar

The provision of persistent, global access to an application's primary destinations, balancing reach against cognitive overhead.

<Story of={ NavBarStories.NavBar } />

Nav bars are the primary UI implementation of the [fully connected](/patterns/fully-connected) navigation model, where every page links to all major sections through global navigation. See [information architecture](/patterns/information-architecture) foundation for the broader structural pattern.

Nav bars can also implement:
- [Multilevel tree](/patterns/multilevel-tree) - when using dropdowns or expandable menus for hierarchical navigation
- Hybrid models - combining global access with contextual navigation
