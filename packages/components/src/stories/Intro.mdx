<h1><i class="muted">Component</i> playground</h1>

<p class="lead">The design-system-ish substrate for the <a href="https://patterns.razvodovskis.com/">pattern playground</a>.
Implementation-wise it is a very mixed bag. Some of the components are written to the best of my ability, others are experimental or proof-of-concept, the rest are vibed through and through. The goal is to support the main playground, try new things, and have some fun.</p>

## Tech stack

<p><a href="https://elenajs.com/">Elena</a> custom elements where a component can stand alone, <a href="https://react.dev/">React</a> where it leans on an ecosystem (<a href="https://tiptap.dev/">TipTap</a> for the editing patterns, <a href="https://tldraw.dev/">tldraw</a> for the canvas), <a href="https://d3js.org/">D3</a> for the charts, all catalogued in <a href="https://storybook.js.org/">Storybook</a>.</p>
