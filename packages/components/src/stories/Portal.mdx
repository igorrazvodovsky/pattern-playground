# Portal

Moves a rendered element somewhere else in the document while the code that owns it stays where it logically lives.

<Story of={PortalStories.EscapeClippingContainer} />

## Accessibility

Moving an element in the DOM moves it in the accessibility tree too. If the portaled content is still owned by a trigger — a listbox for a combobox, say — preserve the relationship with `aria-controls` / `aria-activedescendant` and manage focus deliberately. The visual anchor no longer implies the semantic one.
