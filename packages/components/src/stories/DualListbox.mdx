# Dual listbox

A side-by-side pair of lists — source pool and selection set — with transfer controls between them.

The control realises the staged-commit end of [Selection](/patterns/selection)'s set-size spectrum: the actor moves items from the pool into the selection set and back, with both sides visible, before a surrounding [Form](/patterns/form) or dialog commits the assignment.

## When to reach for it

Compared with a [multiselect](../?path=/docs/components-combobox--docs) (combobox with checked items), which commits items one at a time and never shows the full selected set beside the remaining pool, the dual listbox keeps both sides on screen. It earns its larger surface when the assignment is bulk, the cost of getting it wrong is high, or the actor needs to cross-reference ("am I leaving the right items behind?"). For lighter selection, prefer the combobox.
