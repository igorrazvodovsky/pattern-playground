# Sections

An adaptive container that renders one content structure as either a horizontal tab bar or a stack of collapsible disclosure regions.

<Story of={SectionsStories.Responsive} />

Sections treats the two modes as a single design decision rather than a choice between separate components: one markup structure of headings and content, rendered through whichever affordance the context calls for.

## Related components

- [Tabs](../?path=/docs/components-tabs--docs) — the more complete tab implementation: overflow scrolling, icon and subtitle slots, auto/manual activation
- [Details](../?path=/docs/primitives-details--docs) — the standalone disclosure primitive that Sections' `details` affordance mirrors across multiple siblings
