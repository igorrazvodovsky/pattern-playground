## Autocomplete

The `autocomplete` attribute is one way of helping users complete forms more quickly.
For more complex cases an [autocomplete](/patterns/autocomplete) pattern can be used.

## Related patterns

### Complementary
- [Autocomplete](/patterns/autocomplete) — narrows the option space as the actor types, when a known set exists
- [Autofill](/patterns/autofill) — supplies the value the input would otherwise have to ask for
- <PatternRef slug="good-defaults">Good defaults</PatternRef> — pre-populates the field so the actor only intervenes when the guess is wrong
- <PatternRef slug="suggestion">Suggestion</PatternRef> — offers candidate values the input can adopt, modify, or reject

### Follow-ups
- [Form](/patterns/form) — the container that groups inputs into a coherent ask
- <PatternRef slug="data-entry">Data entry</PatternRef> — the broader activity input contributes to, alongside format and friction choices
- <PatternRef slug="searching">Searching</PatternRef> — where the input becomes the entry point for query formulation

### Tangentially related
- [Textarea](../?path=/docs/primitives-textarea--docs) — chosen instead when the answer doesn't fit a single line
- [Range](../?path=/docs/primitives-range--docs) — chosen instead when the value is bounded and better committed by direct manipulation than by typing
