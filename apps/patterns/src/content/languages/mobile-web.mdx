The patterns run from how the site is reached and moved through, to what a narrow view can hold, to entering data by touch, to feedback the actor takes in at a glance. The library keeps platform differences inside each pattern, so each page's own notes on touch and small screens apply.

The starter leaves out layouts that need a wide screen, such as coordinated views, and routes that need a keyboard, such as shortcuts.
