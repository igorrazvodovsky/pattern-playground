The actor anchors a request in specific material — a file, a selection, a source, a live connection — so the system works from the actor's ground rather than its generalities.

## Forms

Recurring forms: file and image attachment, @-mentions that pull a named thing into the request, removable context chips showing what is in scope, and standing connectors to external sources.
