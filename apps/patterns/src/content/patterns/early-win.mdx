**An actor's interest is highest when they arrive and drops with every step that gives them nothing back. A first run that opens with sign-up, setup questions and a tour asks them to invest before they know whether the artifact is worth it, and many leave before they reach the part they came for.**

The support is practitioner observation. UserOnboard's teardowns describe Duolingo letting people learn real sentences before creating an account, Dropbox's mobile app starting with photos already on the phone, and IFTTT starting from ready-made recipes; Wroblewski made the same case against up-front sign-up forms. The requests that are moved later still have to be made, and a later request needs a reason the actor can see at that moment. A step that feels like progress to the maker, such as customising a template or filling in a profile, does not count as a result unless the actor is better off for it.

Therefore,

**Order the first run so that the first thing the actor finishes is a real result of the kind they came for. Move every request that does not serve that result to after it, and make each one at the point where it is needed.**

A short path to a trivial result is not an early win. Check each early step by asking whether the actor is better off for having done it.

## In practice

### Shortening the path

Some shortcuts remove whole sequences of steps, such as pairing a second device with a QR code or starting from a ready-made automation. Others remove a single step, such as placing the cursor in the first field or filling in a country code from the actor's location. Both count; the first kind usually matters more.

### Generating the first result

Where the artifact can generate content, ask what the actor wants and produce a first draft for them to refine, instead of teaching the tools and showing an empty surface. The actor then learns by editing working content. The draft is generated content and needs the same review as any other; this is [delegating a task](/sequences/delegating-a-task), entered from the first run.
