What the system remembers about the actor is theirs to inspect, correct, scope, and erase — per fact, per conversation, or by stepping outside memory altogether.

## Forms

Recurring forms: a reviewable memory list with per-item deletion, memory scope set per message or per thread, incognito sessions that leave no trace, and graph views of what has accumulated.
