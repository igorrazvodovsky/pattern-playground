# Layout

The layout system determines how an app organizes its elements, establishing visual hierarchies that guide users' attention.

> Substrate: [explore the spacing scale and layout utilities](/storybook/?path=/docs/foundations-material-layout--docs) in Storybook.

## Spacing

- The spacing is structured around a base unit for each density level. It determines the scale used across components.
- T-shirt sizes are used to make differences between levels easier to understand.
- A scale for each [density](/patterns/qualities/density) level is created using the ```base unit``` and ```space increment``` values.

## Grid

Instead of top-down grid system bottom-up approach is used. That is container queries are used to manage each component’s layout.
Additionally, three default utilities are used for common layout solutions. Compositions and patterns either use ready-to-wear solutions
or have context-specific custom layouts and grid solutions.

## Enacted qualities

- Visual [density](/patterns/qualities/density) — base unit and increment values choose how much breathing room each piece of information gets
