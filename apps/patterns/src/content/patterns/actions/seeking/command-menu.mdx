## Related patterns

### Precursors

- <ComponentRef id="operations-combobox--docs">Combobox</ComponentRef> — the mechanism this pattern builds on; `src/components/combobox/` drives the text input, filtered list, and keyboard model
- *Search* establishes user familiarity with typing to filter results, setting expectations that input fields serve navigation and filtering tasks.
- A command palette often extends or consolidates *keyboard shortcut* functionality, making them easier to discover and use.

- *Navigation* menu establishes the baseline structure that a command menu can later streamline or augment.

### Complementary

- *Autocomplete* supports command menu functionality by reducing typing effort and increasing discoverability of commands.
- [Embedded intelligence](/patterns/activities/embedded-intelligence) can help users find relevant commands when exact matches aren't available.
- [Toolbar](/patterns/actions/coordination/toolbar) — exposes a persistent subset of commands; a command menu offers the full set on demand
