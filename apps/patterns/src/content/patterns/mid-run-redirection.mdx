* * *

**Watching an agent pursue a wrong assumption leaves the actor with two poor options: cancel the run and lose the work already done, or wait for a flawed result and revise it afterwards.**

Intervening mid-run trades some simplicity for recovered time and control. Research on interactive reasoning shows that letting actors edit or redirect an active reasoning path increases felt agency and catches errors early, while also adding cognitive load if the actor must parse a long trace or accidentally disturbs a fragile intermediate state.

Therefore,

**Let the actor inject a correction or edit a disputed step while the run is under way, so the agent adjusts its remaining steps from that point without restarting from scratch. Mark where the correction took effect in the trail so the actor can tell which steps came before and after the change.**
