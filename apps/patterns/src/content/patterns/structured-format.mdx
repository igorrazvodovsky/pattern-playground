* * *

**Typing a strict code or identifier into an undifferentiated box gives no clue about the expected syntax and invites transcription errors on long strings. Yet rigid input masks and split fields break copy-paste, reject valid regional formats, and defeat browser autofill.**

Up-front [formality](/patterns/formality) pays off only when the syntax is genuinely fixed and ambiguity is costly. The common mistake is applying a rigid mask to values that only *look* uniform within one country—names, phone numbers, or postcodes—or building visual structure by splitting one value across separate inputs.

Therefore,

**Signal the expected syntax and display long structured values in visual chunks of two to five characters whenever the format is genuinely strict and ambiguity is dangerous. Keep the underlying control a single pasteable input with standard semantic hints so actors can paste, edit, and autofill without fighting the mask.**
