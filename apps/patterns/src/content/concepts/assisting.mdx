---
title: Assisting
added: 2026-10-18
purpose: Offer a member a proposal for the next step of their own work, which they are free to take or leave.
principle: >-
  If a member starts something the system can see the shape of, the system
  proposes a next step beside it; the member takes it, changes it or ignores it,
  and the work is theirs either way.
actions: [suggestOutline]
misfits:
  - A proposal that arrives on every start is noise by the third time.
  - A proposal that is taken without being read makes the system the author.
aliases: [suggestion, assistance, autocompletion]
depends_on: [document-keeping]
appears_in:
  - Google Docs Help me write
  - Notion AI
  - GitHub Copilot
---

The system's own act, caused by a rule rather than by a member. In the fixture
world it fires once, on every document a member writes: the system proposes an
outline. The action adds no facts, which is the point. A proposal is not part
of the record until the member makes it so by editing the document, and the
world has no way yet to say that the edit came from the proposal. The agent
trace work will widen this concept, or replace it, with the activities an
agent carries out on a member's behalf.
