# Practice note: industry systems beside the literature — 2026-08-15

Non-peer-reviewed corroboration for the same run (`query.yml`), kept separate
from the literature note per the research-gate scope rule. Grounded via vendor
documentation, not academic retrieval.

- *Datomic* (docs.datomic.com) is a shipped database whose unit is the datom —
  entity, attribute, value, plus the transaction that asserted it and an
  assert/retract flag. The database "never updates or removes"; retraction is
  a new fact, and the accumulate-only log carries complete history. Two points
  transfer directly: (1) cardinality is declared per attribute in schema
  (`cardinality/one` replaces on assert, `cardinality/many` accumulates) —
  the same requirement the EAV literature surfaced; (2) every fact is stamped
  with the transaction (action) that asserted it, which is a shipped
  precedent for fact-level provenance back to the log.
- *Event sourcing as named pattern* (Fowler, martinfowler.com/eaaDev/EventSourcing.html)
  is the industry articulation the retrieved empirical papers study; its
  standing advice — projections rebuildable at will, events immutable,
  schema change handled by transformation — matches the tactics catalogued in
  Overeem et al.
