# Levels of scale

Property 1 of [the fifteen](index.md).

*As a move* — operand: a zone that jumps from large to small with nothing
between. Operation: differentiate it into parts about one level smaller, so the
sizes form a connected series in which each level helps the ones adjacent to it.

*As a symptom* — structure is legible at several connected sizes; no jump is so
large that the levels stop supporting each other.
