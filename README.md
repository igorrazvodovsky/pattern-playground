# Pattern Playground

A personal design repertoire — a collection of interaction patterns, qualities, and concepts that shape how I approach design problems in work-support tools.

The focus is on mapping relationships between patterns rather than cataloguing components in isolation. It sits somewhere between a design system and a thinking tool: structure enough to be navigable, loose enough to evolve.
